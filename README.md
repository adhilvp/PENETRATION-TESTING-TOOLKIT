**DESCRIPTION**: This repository contains a Python-based Penetration Testing Toolkit with two primary modules: Port Scanner and Brute-Force Attack Module. The Port Scanner is designed to identify open ports on a target system by sending connection requests and analyzing responses, helping security analysts detect potential vulnerabilities. It was tested on scanme.nmap.org, a publicly available and legal target for scanning. The Brute-Force module attempts to crack SSH login credentials using a predefined wordlist, demonstrating the risks of weak passwords. It was tested on TryHackMe’s Hydra Room, a safe environment for practicing brute-force attacks. The toolkit is built using Python and relies on libraries such as socket (for network connections) and paramiko (for SSH brute-forcing). To use the toolkit, install dependencies with pip install paramiko socket, then run the Port Scanner with python port_scanner.py or the Brute-Force module with python bruteforce.py. The repository includes proof of execution through screenshots of successful port scans and brute-force attempts. This project is strictly for educational and ethical hacking purposes and should only be used on authorized systems. Unauthorized usage on external networks is strictly prohibited.
